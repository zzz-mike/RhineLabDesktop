# 莱茵生命 · Mac 本地接入版 v0.2.0

适用于 macOS 12 或更新版本（Apple Silicon / Intel）的本地浏览器版本。包含纯展示版的画质、三维档案和工作台，并提供按需授权的文件夹与本机服务连接。Windows 请使用 RhineLabDisplay；本包的文件选择与打开操作尚未适配 Windows。

## 启动与授权

1. 从 https://nodejs.org/ 安装 Node.js 22.12 或更新版本，解压整个 `RhineLabMacLocal` 文件夹。
2. 双击 `Start-Mac.command`，或在该文件夹里运行 `node server.mjs`。
3. 浏览器打开 http://127.0.0.1:5191/connections 。所有连接默认关闭；可直接“返回莱茵生命”使用内置档案。
4. 需要本地文件时点击“选择并授权文件夹…”，在系统目录选择窗口选择具体目录并点“允许读取此文件夹”。建议先用测试目录；不允许直接选择整个磁盘根目录或整个用户目录。
5. 授权范围包括所选目录内的文件名、子目录、预览内容。默认不允许打开外部应用；如需打开文件或在访达定位，再单独勾选并保存。
6. 在“本地连接”点击“断开全部”会撤销文件夹及服务连接、清除本次访问缓存和预览令牌，终止正在返回的数据；其他本软件页面会刷新。已在外部程序打开的文件不会被强制关闭。
7. 授权仅保存在服务进程内存里，停止服务或重启后全部关闭。按 Ctrl+C 停止服务。

文件不会自动上传；不提供删除、移动或修改原文件的接口。隐藏文件和越出授权目录的符号链接不可读取。用户主动打开文件时，后续行为由对应外部应用负责。

## 系统权限与限制

软件按选定目录限制访问，但当前程序不是 macOS 沙盒应用，也未经 Apple 公证。macOS 可能按启动方式对终端、Node 或相关进程提示文件访问权限；不要为了运行它开放完全磁盘访问。如果系统阻止启动，请保留安全保护，并先核验来源或使用纯展示版。

本包附带 Apple Silicon / Intel 通用文件夹选择器，无需为它安装编译工具。完整源码（mac/choose-folder.m）在仓库提供。

AI 秘书、光伏和媒体连接分别默认关闭，勾选并保存后才会访问对应本机服务；这些后端、媒体工具及业务数据不随包提供。授权文件夹不会顺带读取 AI 秘书保存的桌面摘要。未配置服务时相关组件显示未连接或不可用。
